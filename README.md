#  Bootstrap Base

##  Sobre o Projeto

Este repositório foi criado para praticar o desenvolvimento de páginas web utilizando o **Bootstrap**, um dos frameworks CSS mais populares para criação de interfaces responsivas. O projeto serve como base para estudos e para o desenvolvimento de novas páginas e aplicações.

---

##  Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Git
- GitHub

---

##  Estrutura do Projeto

```text
bootstrap_base/
│
├── css/
├── js/
├── img/
├── index.html
└── README.md
```

> A estrutura pode variar conforme os arquivos do projeto.

---

##  Objetivos

- Aprender os componentes do Bootstrap;
- Desenvolver páginas responsivas;
- Praticar o uso do sistema de grid;
- Criar layouts modernos e organizados.

---

##  Recursos Utilizados

- Sistema de Grid
- Botões
- Cards
- Navbar
- Formulários
- Alertas
- Responsividade

---

##  Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/AndressaPapini/bootstrap_base.git
```

2. Abra a pasta do projeto.

3. Execute o arquivo `index.html` em qualquer navegador.
